## 1. 왜 바꾸나
- 처음 양식은 "한 줄 = 변수 하나 = 계수 하나"였어.
- 아크그리드는 코어 6개 × (등급, 포인트)로 이루어진 **구성**이라서, 줄 하나로는 표현할 수 없어.
- 측정을 보면 계통마다 효과가 나타나는 모양이 서로 달라.

| 모양 | 예 | 근거 |
|---|---|---|
| 비례 (선형) | 팔찌 추가 피해 · 적주피 · 치피, 각인 레벨, 목걸이 % | ±가 대칭이야 (아드레날린 ±80.77, 팔찌 추피 ±22.61) |
| 계단 (표) | 보석 레벨, 아바타 등급, 아크패시브 랭크, 스톤 각인, 코어 포인트 | 특정 값에서만 변해 (코어는 10/14/17/18/19/20) |
| 곡선 (보간) | 재련, 무기 품질, 악세 · 팔찌 스탯, 아크그리드 젬, 팔찌 치적 | 증가 폭이 구간마다 달라 |

그래서 **계통마다 컴포넌트를 두고, 각 컴포넌트가 자기 효과 모델을 들고 있는 구조**로 바꿔.

## 2. 예측식
```
예측 전투력 = API 전투력 × Π_c [ F_c(변경 후 상태) / F_c(현재 상태) ]
```
- `F_c`는 컴포넌트 c의 배율이야. 기준 캐릭터 상태에서는 1.0이야.
- 현재 상태와 변경 후 상태의 **비율**만 쓰기 때문에, 기준 캐릭터가 아닌 캐릭터에도 같은 표를 쓸 수 있어. 이 부분은 검증 시트로 확인해야 해.
- 같은 칸(버킷)에 들어가는 효과는 더하고, 다른 칸끼리는 곱해. 어떤 효과가 어느 칸인지는 `효과-칸 표`와 `쌍 실험`으로 확정해. 확정되기 전까지는 모든 컴포넌트를 곱하는 방식으로 계산해.

## 3. 효과 모델 (전략 패턴 + 팩토리 메서드)
| Model | 계산 | JSON 필드 |
|---|---|---|
| `LINEAR` | F(x) = 1 + PerUnit · (x − Origin) | `Origin`, `PerUnit`, `Points` (검산용) |
| `TABLE` | 키가 정확히 일치하는 값을 찾아. 없으면 아래쪽 이웃 값을 써 (계단) | `Points: [[키, 배율], ...]` |
| `CURVE` | 측정점 사이는 선형 보간, 양 끝 밖은 끝 구간 기울기로 외삽 | `Points: [[x, 배율], ...]` |
| `ARK_GRID` | F = Π_i T(등급_i, 포인트_i). T는 코어 1개의 배율 = (전체 6개 배율)^(1/6) | `Rows: [[등급, 포인트, T], ...]`, `ZeroPower` |

### 아크그리드 결합 방식 근거
- 코어 6개를 같은 등급 · 포인트로 바꾼 측정 19개가 있어. 이걸로 기준 혼합 구성(고18 유18 고20 고18 유18 유17)을 예측해서 비교했어.

| 방식 | 예측 | 실측 | 오차 |
|---|---|---|---|
| 기하평균 (log 합) | 4703.27 | 4702.90 | **+0.008%** |
| 산술 합 (배율−1 합) | 4706.01 | 4702.90 | +0.066% |

- 기하평균 쪽이 더 잘 맞아서 `Combine: GEOMETRIC`으로 정했어.
- 슬롯(해/달/별) 차이는 아직 몰라. 코어 시트의 "코어 하나만 바꾼 측정"으로 확인할 거야.
- 슬롯 차이가 있으면 `Keys`에 `Slot`을 추가해.

### 악세는 부위가 아니라 옵션 합계 (2026-11-07 추가)
- 귀걸이 두 짝은 옵션 값이 서로 달라. 무기 공격력%가 귀걸이1은 3, 귀걸이2는 1.8이야.
- 그래서 "1번에서 0으로" 바꿀 때와 "2번에서 0으로" 바꿀 때 빠지는 양이 달라. 전투력 변화가 다르게 보였던 건 이 때문이야.
- 스탯 측정 15점(목걸이, 귀걸이 2개, 반지 2개)을 **주스탯 합계**를 x축으로 놓으면 직선 하나에 모여. 기울기는 7.14973e-07/스탯이고, 최대 오차는 0.0000038이야. 전투력으로 치면 0.02 정도야.
- 따라서 악세 컴포넌트의 x는 장착한 5부위의 옵션별 합계로 해. 실험 양식의 `악세 합계` 시트에 지금 장착한 부위별 값을 적어 둬.
- 단일 실험 줄에는 [바꾼 부위]와 부위 값 전/후만 적어. 그러면 합계 전/후가 자동으로 계산돼.
- 귀걸이 무기 공격력%와 공격력%는 귀걸이1과 귀걸이2를 각각 3줄씩 측정해. 두 귀걸이의 점이 같은 선에 모이면 이 방식이 확정이야.
- 같은 옵션 이름이면 부위가 달라도 하나로 합쳐. 예를 들어 공격력+는 목걸이 80 + 반지2 390 = 470이야.
- 목걸이 추가 피해%는 0.7 / 1.6 / 2.6 세 점이 직선에서 최대 0.0011 벗어나. 측정점이 더 쌓이면 CURVE로 바꿀지 다시 판단해.

## 7. 확인 필요 데이터 (v2에서 주황 칸으로 표시)
1. **아크그리드 고대 0 / 10 / 14p**
   - 각각 유물 20p, 0p, 유물 10p와 값이 똑같아. 행이 밀린 것 같아.
   - 원래 쌍 실험 시트에는 고대 0p가 3509.49로 적혀 있었어.
   - 재측정이 필요해서 내보낼 때 뺐어.
2. **팔찌 - 특화 · 팔찌 - 치명**
   - 전투력이 팔찌 - 신속 줄과 완전히 똑같아. 치명 0→0인데도 −95.82로 적혀 있어.
   - 복사 오류로 보여서 재측정이 필요하고, 내보낼 때 뺐어.
3. **측정 대기**: 귀걸이 무공+ · 공% · 무공%, 반지 공+ · 무공+ · 치적 · 치피.
4. **아크패시브 진화 레벨, 도약 레벨, 깨달음 랭크**: 측정 결과 변화가 0이야. 로아랩이 반영하지 않는 값인지 다시 확인해 줘.
