# 🪙 로스트아크 멀티툴(LOSTARK MULTI-TOOL)

---

## 개발의도
1. 귀속재료 계산기 : 귀속재료 수급량이 지속적으로 늘어남에 따라 각 캐릭별 & 원정대 총합으로 가치가 얼마인지 궁금해서 만들었음
2. 보석 최저가 검색기 : 여러 사이트에서도 볼 수 있지만 프로그램 딸깍으로 보면 편하지 않을까 싶어서 만들었음
3. 낙원력 트래커 : 개인적으로 기록하는 걸 좋아하는데 엑셀로만 하다보니까 귀찮아서 만들었음
4. C#으로 3개를 만들었는데 프로그램 3개 키기 귀찮아서 올인원으로 3개 합쳐버림!
5. 합친 김에 자주 확인하는 시세(유각 · 악세 · 강화책 · 젬)도 한 프로그램에서 보려고 탭을 더 늘렸음!

- 모든 시세 탭은 **[5분마다 자동 갱신]**을 켜 두면 다른 탭을 보고 있거나 트레이에 숨어 있어도 계속 갱신해요!
- 시세가 직전 갱신보다 오르면 🔺빨강, 내리면 🔻파랑으로 보여줘요!

* 귀속재료 계산기

## ✨ 주요 기능

- **원정대 자동 불러오기** : 닉네임 하나만 입력하면 원정대 캐릭터를 아이템 레벨 순으로 불러와요!
- **실시간 시세 계산** : 로스트아크 공식 API로 거래소 시세를 가져와서 재료 값어치를 계산해요!
- **상위 / 하위 재료 구분** : 결정·위대한·상급 재료와 일반 재료를 따로 계산해요! (1730 이상 캐릭터는 상위, 미만은 하위 수량만 입력)
- **캐릭터 자산 / 원정대 자산** : 고른 캐릭터의 자산과 원정대 전체 자산을 함께 보여줘요! 원정대 자산 줄에는 재료별 원정대 전체 보유수량도 표시돼요!
- **시세 등락 표시** : 직전 갱신보다 오르면 🔺빨강, 내리면 🔻파랑으로 보여줘요!
- **자산 그래프** : 하루 한 번 원정대 총 자산을 기록해서 변동 추이를 그래프로 보여줘요! (마우스를 올리면 날짜 · 자산 말풍선)
- **백그라운드 자동 갱신** : 최소화하면 트레이로 들어가서 5분마다 시세를 갱신해요! (트레이 아이콘에 마우스를 올리면 원정대 자산이 보여요)
- **자동 백업** : 저장 파일이 손상되면 백업에서 자동으로 복구해요!

* 보석 최저가 검색

## ✨ 주요 기능

- **레벨·종류별 최저가 표** : 겁화·작열 7~10레벨의 즉시 구매 최저가를 한 번에 보여줘요!
- **시세 등락 표시** : 직전 조회보다 오르면 🔺빨강, 내리면 🔻파랑으로 표시해요! (재시작해도 이어서 비교)
- **목표가 알림** : 보석과 목표가를 등록하면, 그 가격 이하 매물이 나왔을 때 트레이 알림을 보내요!
- **2단 자동 갱신** : 알림 건 보석은 10초마다, 표 전체는 1분마다 확인해요! (주기 변경 가능)
- **호출 한도 자동 보호** : 남은 API 호출 수를 보여주고, 한도에 가까워지면 알아서 잠깐 쉬어요!
- **시세 기록 그래프** : 보석별 하루 최저가를 기록해서 추이를 그래프로 보여줘요!
- **백그라운드 실행** : 최소화하면 트레이로 들어가서 계속 확인해요!

## 🔍 정확한 최저가를 위한 처리

- 경매장 검색은 이름 **부분 일치**라서 다른 레벨이 섞여 나올 수 있어요 → 이름이 **정확히 같은** 매물만 비교해요
- 즉시 구매가가 없는 **입찰 전용 매물은 제외**해요
- 조회 중 하나라도 실패하면 그 회차는 반영하지 않아요 (일부만 바뀐 엉터리 표가 생기지 않도록)

## ✨ 주요 기능

- 원정대 연동을 하면 모든 캐릭터를 불러와요
- 주차추가를 통해 해당 시즌의 주차를 설정한 후에 일주일에 딱 한 번씩만 기록하면 돼요!
- 시즌추가를 통해 다음시즌 낙원도 미리 대비할 수 있어요!
- **총합 낙원력** : 원정대 모든 캐릭터의 낙원력 총합을 표시해요!
- **평균 낙원력** : 각 주차별로 평균 낙원력을 산출해서 표시해요!
- **전주 대비 상승률** : 바로 직전 주에 비해서 평균 낙원력 상승량을 수치화했어요!
- **첫주 대비 상승률** : 매 시즌의 첫주차 대비 상승한 수치를 보여줘요!
- **평균 낙원력 변동폭 그래프** : 하단에 크게 평균 낙원력을 기반으로 그래프로 변동폭을 알 수 있어요!
- **닉네임 변경 감지** : 원정대 동기화 때 닉네임만 바뀐 캐릭터를 찾아서 기록을 새 이름으로 옮겨줘요!
- **기존 기록 가져오기** : 예전 C# 낙원력 트래커를 쓰고 있었다면 처음 실행할 때 기록을 한 번 가져와요! (원본 파일은 그대로 둬요)

## ✨ 주요 기능

- **부위 선택** : 목걸이 · 귀걸이 · 반지 (4티어 **고대** 등급 고정)
- **딜러 유효 연마 옵션만** : 부위마다 딜러에게 의미 있는 연마 효과만 골라서 보여줘요!

| 부위 | 고를 수 있는 연마 효과 |
|---|---|
| 목걸이 | 추가 피해 / 적에게 주는 피해 증가 / 공격력+ / 무기 공격력+ |
| 귀걸이 | 공격력+ / 공격력% / 무기 공격력+ / 무기 공격력% |
| 반지 | 공격력+ / 무기 공격력+ / 치명타 적중률 / 치명타 피해 |

- **조건 검색** : 최소 품질 + 연마 효과 최대 3개(효과마다 최소 수치)로 경매장을 검색해요!
- **결과 표** : 이름 · 품질 · 옵션 · 즉시 구매가 · 최소 입찰가 · 거래 가능 횟수 · 마감 시간을 즉시 구매가 낮은 순으로 보여줘요!
- **페이지 이동** : **◀ 이전 / 다음 ▶** 으로 다음 결과를 볼 수 있어요!

* 젬 시세 검색기 + 귀속 젬 계산기

## ✨ 주요 기능

- **질서의 젬** (안정 · 불변 · 견고) / **혼돈의 젬** (침식 · 왜곡 · 붕괴) 의 **영웅** 등급 시세를 두 표로 보여줘요!
- **귀속 젬 계산기** : 귀속 젬(고급 · 희귀 · 영웅) 보유수량을 입력하면 거래소 시세로 가치를 계산해요!
  - 단가는 **최근 거래가**, 없으면 **현재 최저가**를 써요
  - **캐릭터별**로 입력하고, **★ 캐릭터 가치 ★** 와 **★ 원정대 총 가치 ★** 를 함께 보여줘요!
  - 캐릭터 선택에서 **★ 원정대 전체 ★** 를 고르면 모든 캐릭터의 수량을 합쳐서 보여줘요! (합계라서 수정은 캐릭터를 골라서 해요)
  - 원정대 동기화는 **아이템 레벨 1700 이상** 캐릭터만 불러와요!

* 전투력 시뮬레이터

## ✨ 주요 기능

- 캐릭터 이름으로 **무기고를 불러와서** 장비 · 악세 · 팔찌 · 스톤 · 각인서 · 보석 · 아바타 · 아크 패시브 · 아크 그리드를 보여줘요!
- 위쪽 **결과 막대**에 현재 전투력(API) → **예상 전투력 · 증감(%) · 예상 아이템 레벨**과 계통별 배율이 항상 떠 있어요!
- 아래 **카드 6장**에서 목표값을 바꿔요!
  - 장비 재련 · 완갑 / 악세서리 연마 옵션 5종 / 아크 그리드(코어 6 · 젬 효과)
  - 보석 · 무기 품질 / 팔찌 · 어빌리티 스톤 · 각인서 / 아크 패시브 · 아바타
- 보석은 **한 번에** 또는 **보석마다** 목표 레벨(6 ~ 10)을 고를 수 있어요!
- 로펙 시뮬레이터 측정 데이터로 맞춘 **추정치**예요! 계통 하나만 바꾸면 오차는 대부분 **0.1% 이내**예요.
  - 완갑은 한계 해방 추가 효과(기본 공격력 영웅 0% · 전설 1% · 유물 2% · 고대 3%)까지 반영해요! 등급은 [아크 패시브 · 아바타] 카드 맨 아래에서 고를 수 있어요.
  - (v1.5.1) 스톤 각인은 같은 이름 각인서 효과에 더해서 계산해요! 각인서 · 스톤 조합 오차가 약 0.6% 수준으로 줄었어요.
  - (v1.5.3) 전설 각인서는 유물 X0에서 남은 단계만큼 낮게 계산하고, 스톤 각인 효과는 이름별로 다시 맞췄어요!
  - (v1.5.2) 아크 패시브 랭크 × 깨달음 포인트 조합, 아바타 여러 부위 동시 변경 계산을 고쳐서 오차가 0.05% 이내예요!
  - (v1.5.4) 아크 패시브 랭크는 진화 · 깨달음 · 도약 트리별로 읽어서 계산해요! 랭크가 덜 찬 캐릭터 오차가 7.6% → 0.6% 이내로 줄었고, 직업 각인 51개 모두 6랭크 기준 0.03% 이내예요.
  - 아직 근사로 계산하는 항목: 스톤 1번 줄 없음 · 깨달음 포인트 구성 · 처음 보는 혼돈 코어

2. **GET ACCESS TO LOSTARK API** 메뉴에서 클라이언트를 만들고 API 키를 발급받아요!


### 2. 처음 실행
1. `LOA-MULTITOOL.exe`를 실행해요
2. 먼저 서버 상태를 확인해요! (점검 중이면 안내 후 종료 · 새 버전이 있으면 업데이트 안내 · 공지가 있으면 표시)
3. API 키 입력 창이 뜨면 발급받은 키를 붙여넣고 **[저장 및 시작]**을 눌러요! (모든 탭이 키 하나를 같이 써요)


### 3. 원정대 불러오기
1. 탭의 이름 입력칸에 **아무 캐릭터 닉네임**이나 입력해요!
2. **[원정대 동기화]**를 누르거나 Enter를 누르면 원정대 캐릭터가 목록에 추가돼요!
   - 귀속재료 계산기 · 낙원력 트래커 · 젬 시세 검색기는 각각 원정대를 불러와요

### 4. 트레이
- 창을 최소화하면 작업 표시줄 대신 트레이로 들어가서 뒤에서 계속 돌아가요!
- 트레이 아이콘 더블클릭 = 열기 / 우클릭 = **열기 · API 키 변경 · 종료**
- 숨어 있는 동안 생긴 알림은 트레이 풍선으로 알려줘요!

### 5. 편의
- 버튼과 체크 상자는 Space로도 누를 수 있어요!
- 목록은 방향키 · Home · End · 휠로도 움직일 수 있어요!
- 표의 수량 칸은 누르고 숫자를 입력하면 바로 저장돼요! (Enter · Tab · 다른 곳 클릭 = 확정, Esc = 취소)

## 🚀 사용법(개별사항)

### 3-1. 귀속재료 계산기

- 보유수량 입력
1. 목록에서 캐릭터를 골라요!
2. 표의 **보유수량(상위) / 보유수량(하위)** 줄에 그 캐릭터가 가진 재료 수량을 입력해요! (레벨에 맞는 줄만 입력할 수 있어요)
3. 입력하면 바로 저장되고, 캐릭터마다 따로 기록돼요!
4. **[시세 갱신]**을 누르거나 **[5분마다 자동 갱신]**을 켜면 시세를 불러와서 다시 계산해요!

---

### 3-2. 보석 최저가 검색기

### 1. 시세 보기
- **[시세 갱신]** 버튼을 누르면 표 전체를 조회해요!
- 표의 칸을 클릭하면 그 보석이 그래프와 알림 입력칸에 바로 선택돼요! (목표가 칸에 현재가가 채워져요!)

### 2. 목표가 알림 걸기
1. 보석을 고르고 목표가를 입력한 뒤 **[추가/변경]**을 눌러요!
2. 같은 보석에 다시 추가하면 목표가만 바뀌어요!
3. 최저가가 목표가 이하로 **새로** 내려오면 알림이 한 번 와요!
   - 가격이 다시 오르면 알림이 다시 준비되고, 다음에 또 내려오면 또 알려줘요!

### 3. 자동 갱신
- **[자동 갱신]**을 체크하면 시작해요
- **감시** : 알림 건 보석만 확인하는 주기 (10 / 15 / 30 / 60초)
- **전체** : 표 전체를 확인하는 주기 (1 / 3 / 5분)

---

### 3-3. 낙원력 트래커

### 1. 낙원력 기록
1. 증명 + 천상을 다 돈 후 해당 캐릭터의 해당 주차의 최종 낙원력을 입력해요!
2. 우측 필드값(총합 / 평균 / 전주대비(%) / 첫주대비(%))이 자동으로 계산돼요!
3. 입력된 수치 기반으로 하단의 그래프도 자동으로 만들어지고 곡선형 그래프로 표시돼요!
4. 그래프의 꼭짓점에 마우스를 올리면 원이 살짝 커지면서 '직전 기록 대비' 상승량이 표기돼요!
5. 최고 달성 낙원력 기준으로 그래프의 수치가 금색으로 표기돼요!
6. y 축에는 달성 최고 평균 낙원력이 가로선으로 표기돼요!

### 2. 주차 & 시즌 추가
- **주차 추가** 버튼을 누르면 상단표 최하단에 N주차가 추가돼요!
- **시즌 추가** 버튼을 누르면 새로운 페이지가 열리고 주차추가를 통해서 다음 시즌도 새로 기록할 수 있어요!
- **시즌 N** 드롭박스를 통해서 시즌별로 기록을 볼 수 있어요!
- **시즌 번호 변경** 은 개발하다 보니 시즌 1로 시작이 되다 보니 지금 기준에 맞추기 위해 추가된 부분이라 추후 패치를 통해 없어질 예정이에요!

---

### 3-4. 유각 시세 검색기

1. **[시세 갱신]**을 누르면 유물 각인서 시세를 모두 불러와요!
2. 검색칸에 각인 이름을 입력하면 바로 걸러지고, **정렬**에서 순서를 바꿀 수 있어요!

---

### 3-5. 악세 검색기

1. **부위**(목걸이 · 귀걸이 · 반지)와 최소 **품질**을 골라요!
2. 연마 효과 칸(최대 3개)에서 원하는 효과와 최소 수치를 골라요! (부위를 바꾸면 그 부위의 딜러 옵션으로 바뀌어요)
3. **[검색]**을 누르면 즉시 구매가 낮은 순으로 결과가 나와요! **◀ 이전 / 다음 ▶** 으로 페이지를 넘겨요!

---

### 3-6. 강화책 검색기

1. **[시세 갱신]**을 누르면 야금술 · 재봉술 시세를 불러와요!
2. **[5분마다 자동 갱신]**을 켜 두면 계속 최신 시세로 유지돼요!

---

### 3-7. 젬 시세 검색기

1. **[시세 갱신]**을 누르면 질서 · 혼돈의 젬 시세를 불러와요!
2. 아래 **귀속 젬 계산기**에서 대표 캐릭터 이름을 넣고 **[원정대 동기화]**를 눌러요! (1700 이상 캐릭터만)
3. 캐릭터를 고르고 젬 · 등급별 **수량 칸**에 보유수량을 입력하면 바로 저장되고 가치가 계산돼요!
4. **★ 원정대 전체 ★** 를 고르면 원정대 합계를 볼 수 있어요!

> 💡 예전 버전(원정대 공용 수량)에서 입력한 귀속 젬 수량은 처음 원정대 동기화를 할 때 레벨이 가장 높은 캐릭터에게 옮겨져요.

---

### 3-8. 전투력 시뮬레이터

1. 캐릭터 이름을 넣고 **[조회]**를 누르면 무기고를 불러와요!
2. 카드에서 항목을 고르고 **목표** 칸을 바꿔요! 숫자 항목은 목표 칸을 눌러 바로 입력하고, 선택 항목은 아래 선택지에서 골라요!
3. 보석은 **[모든 보석 목표 레벨]**로 한 번에 바꾸거나 보석마다 따로 골라요!
4. 위쪽 결과 막대에서 **예상 전투력 · 증감**을 바로 확인해요!

> 💡 API 전투력에 로펙 측정 기반 배율을 곱한 추정치라서, 실제 인게임 수치와 약간 다를 수 있어요.

## 📊 호출 한도 안내

로스트아크 API는 **분당 100회**까지 호출할 수 있어요. **모든 탭이 API 키 하나를 같이 쓰기 때문에** 한도도 함께 나눠 써요.
보석 최저가 검색기 상단에 `남은 호출 85/100 · 예상 분당 약 20회`처럼 표시돼요.

| 설정 예시 (보석 검색기) | 분당 호출 |
|---|---|
| 알림 2개 · 감시 10초 · 전체 1분 | 약 18회 |
| 알림 4개 · 감시 10초 · 전체 1분 | 약 28회 |
| 알림 8개 · 감시 10초 · 전체 1분 | 약 48회 |

- 전체 갱신 차례에는 알림 보석도 함께 조회하므로 같은 보석을 두 번 조회하지 않아요
- 예상 호출량이 한도에 가까우면 **주황색**으로 알려줘요
- 남은 호출로 이번 갱신을 끝까지 할 수 없으면 시작하지 않고, 초기화될 때까지 쉬어요 (`⏸ 호출 한도 보호 중`)
- 다른 탭의 자동 갱신도 남은 호출이 부족하면 그 회차는 건너뛰어요
- 호출 한도를 넘겼거나 서버 점검 중이면 자동 갱신을 잠시 멈췄다가 다시 시도해요 (점검 중에는 5분 간격)
- 같은 API 키를 쓰는 다른 프로그램이 있으면 한도를 **나눠 써요**

> ⚠️ 아주 싼 매물은 몇 초 만에 팔리는 경우가 많아요.
> 알림은 "이 가격대 매물이 나오기 시작했다"는 신호로 보고, 목표가를 살짝 여유 있게 잡는 걸 추천해요.

## ❓ 문제 해결

| 증상 | 해결 방법 |
|---|---|
| "API 키가 유효하지 않습니다" | 트레이 아이콘 우클릭 → **[API 키 변경]**으로 다시 입력해 주세요 |
| "API 호출 한도를 초과했습니다" | 잠시 후 다시 시도해 주세요. 알림 수를 줄이거나 감시 주기를 늘리면 좋아요 |
| "서버 점검 중입니다" | 로스트아크 점검이 끝난 뒤 다시 시도해 주세요 |
| 표에 "매물 없음"이나 "-"가 떠요 | 즉시 구매 가능한 매물이나 거래 기록이 지금 없는 거예요 |
| 보석 알림이 "-"로만 보여요 | 6레벨 이하 알림은 조회 대상이 아니에요. 삭제해 주세요 |
| 젬 탭에 캐릭터가 안 나와요 | 귀속 젬 계산기는 아이템 레벨 1700 이상 캐릭터만 불러와요 |
| "데이터 파일을 열 수 없습니다" | 백신 검사 등으로 파일이 잠깐 잠긴 경우예요. 잠시 후 다시 실행해 주세요 |
| "저장 파일이 손상되어…" 안내가 떠요 | 백업에서 자동 복구된 거예요. 손상된 원본은 `.corrupt_날짜` 파일로 남아 있어요 |

## 📁 데이터 저장 위치

모든 데이터는 아래 폴더에 저장돼요.

```
%LocalAppData%\LostArkMultiTool\
```

| 파일 | 설명 |
|---|---|
| `LostArkRosterData.json` | 귀속재료 계산기 : 원정대, 보유수량, 자산 기록 |
| `GemFinderData.json` | 보석 최저가 검색기 : 목표가 알림, 시세 기록, 갱신 주기 설정 |
| `ParadiseTrackerData.json` | 낙원력 트래커 : 시즌 · 주차 기록 |
| `BoundGemData.json` | 젬 시세 검색기 : 캐릭터별 귀속 젬 보유수량 |
| `APIKey.dat` | API 키 (Windows 계정 단위로 암호화, 모든 탭 공용) |
| `*.json.bak` | 직전 저장본 (자동 백업, 지우지 마세요) |
| `*.json.corrupt_*` | 손상되어 보관된 파일 (복구가 끝났으면 지워도 돼요) |

- 유각 · 악세 · 강화책 · 젬 시세는 실행 중에만 보관하고 파일로 저장하지 않아요.
- 보석 시세 기록은 최근 365일까지만 보관돼요.
- 저장할 때는 임시 파일에 먼저 쓰고 바꿔 끼우기 때문에, 저장 도중 꺼져도 파일이 깨지지 않아요.
- API 키는 Windows DPAPI로 암호화돼서, **같은 PC의 같은 Windows 계정**에서만 풀 수 있어요. 다른 곳으로 전송되지 않아요.
